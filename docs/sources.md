# 出典

出典データの単一ソースは `src/data/sources.ts`。アプリ内では `/sources` と各詳細ページで確認できる。ここでは方針と、用いた発行主体の一覧を示す。

## 方針

- 美術館・大学・研究機関・専門プラットフォームの**公開ページ**のみを用いる。
- 一般ブログ・まとめサイトのみを根拠にしない。
- 各出典は `title` / `publisher` / `url` / `accessed`（参照日）/ `kind` / `reliability` / `supports`（対応する記述）を保持する。
- 全 URL は参照日（2026-07-23）時点で到達可能性を確認した。
- 信頼性区分：`high`＝一次的な美術館・大学・専門事典、`medium`＝展覧会解説・教育向け二次資料・作家公式。

## 一次資料の確認について

初期データの文章は上記資料に基づく要約・整理である。各記述の根拠は対応する出典に帰属する。逐語引用ではないため、正確な研究には各出典ページおよび専門文献を直接参照すること。出典 URL・内容の権利は各機関に帰属する。

## 追加方法

`src/data/sources.ts` に `Source` 型で追加し、対象エンティティの `sourceIds` から参照する。追加後に `npm run validate:data` で URL 形式・参照整合性を検証する。
