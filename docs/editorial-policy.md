# 編集方針・情報品質・出典方針

アプリ内の記述は日本語。固有名詞には必要に応じて原語・英語を併記する。

## 編集原則

1. **発展史観を単純化しない** — 「未熟な中世から写実的なルネサンスへ進歩した」という直線的説明を避ける。各時代には異なる目的・価値基準・鑑賞環境があった。
2. **カメラの発明を単純な断絶として扱わない** — 写真以前の絵画にも宗教・儀礼・権力の正当化・記憶・教育・装飾・身分表示・空間構成・想像世界の可視化といった機能があったことを示す。
3. **地域差を示す** — 同時代のイタリア・北方ヨーロッパ・日本などを並行して扱い、単一の時間軸へ無理に統合しない。時代×地域マトリクスがこの方針を体現。
4. **思想と形式を接続する** — 「明暗が強い」「平面的」等の形式的特徴を、宗教・哲学・制度・技術・鑑賞者の身体との関係まで説明する。
5. **鑑賞者の視点の変化を横断テーマにする** — 象徴的空間／単一視点遠近法／鑑賞者の巻き込み／主観的知覚／平面性／物質性／身体性／展示空間／インスタレーション／没入環境／デジタル空間。

## 情報品質のルール

- 複数資料で確認できない事項は断定しない。
- 年代に諸説がある場合は幅を持たせ、`dates.circa` と `note` で明示する。
- 学術的に議論がある内容は「見解の一つ」と明示する。
- **事実と解釈を区別する**。
- AI（Claude）の推論を歴史的事実として記載しない。
- 出典を確認できない項目には `verification: 'needs-review'`（要確認）を付す。
- 自動生成された架空の引用や URL を作らない。

## 関係データの編集基準

### 継承

前の運動の中心的な方法・問題意識・形式を、次の運動が引き継ぎ発展させた関係。

- 比較的近い時代の系譜である。
- 中心的要素を引き継いでいる。
- 後続運動の成立説明に不可欠である。
- 一部技法だけでなく、運動の構造に関わる。
- 判定補助: その関係を除くと、後続運動の成立説明が大きく崩れる。
- 例: 印象派 → ポスト印象派。

### 影響

特定の技法・思想・作品・作家が、別の運動の一部に作用した関係。直接的な後継関係である必要はない。

- 時代・地域が離れていてもよい。
- 一部の要素だけでも成立する。
- 直接の系譜ではない。
- 複数方向から成立しうる。
- 判定補助: 成立の一因だが、直接の後継関係ではない。
- 例: 浮世絵 → 印象派。

既存データを再分類する場合は、表示上の都合だけで自動変更しない。出典と note を確認し、監査候補として記録したうえで編集判断を行う。

`from` は作用の起点、`to` は作用を受けた到達先。反発は「反発された側 → 反発した側」で保持し、本文では「`to` は `from` に反発した」と自然な主語で表示する。

## 情報確認状態（verification）

| 値 | 意味 |
| --- | --- |
| `verified` | 複数の信頼できる資料で確認 |
| `single-source` | 単一資料に基づく |
| `contested` | 学術的に諸説あり（見解の一つ） |
| `needs-review` | 要確認 |

UI では色のみに依存せず、記号（●◐◈▲）とテキストで併記する。

## 出典方針

- 美術館・大学・研究機関・専門プラットフォーム（The Met、MoMA、Tate、Guggenheim、Smarthistory、National Gallery、Getty、V&A、国立西洋美術館・東京国立近代美術館等）の**公開情報**を優先する。
- 一般ブログ・まとめサイトのみを根拠にしない。
- 各ムーブメント・作家・作品・関係に出典（`sourceIds`）を紐づける。
- 出典データは `title` / `publisher` / `url` / `accessed` / `kind` / `reliability` / `supports`（対応する記述）を保持し、UI（`/sources`・各詳細ページ）で確認できる。
- URL は参照日時点で到達可能性を確認する。

## AI 生成に関する注意

初期データの文章は、上記の公開資料に基づく**要約・整理**である。特定の一文を逐語的に引用したものではなく、内容の裏づけは各エンティティの出典に帰属する。年代・解釈には学術的議論があり、正確な研究には各出典・専門文献を直接参照すること。誤りは出典に基づく修正を歓迎する。
