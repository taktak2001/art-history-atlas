# 関係タイプ定義監査

実施日: 2026-07-24

対象: `src/data/relationships.ts` の既存関係

方針: 継承と影響の新しい判定基準を既存 note へ照合した。表示改善と同時に関係データを自動修正せず、編集者が出典を再確認すべき候補だけを記録する。

## 定義

- 継承: 前の運動の中心的方法・問題意識・形式を後続運動が引き継ぎ、成立説明に不可欠な構造的関係。
- 影響: 技法・思想・作品・作家など一部の要素が作用した関係。直接の後継関係でなくても成立。
- 判定補助: 関係を除くと後続運動の成立説明が大きく崩れるなら継承、成立の一因に留まるなら影響。

## 維持が妥当と判断した代表例

- `rel-realism-to-impressionism`（継承）: 同時代性と独立展という運動の基盤を引き継ぎ、光と知覚へ展開する説明。
- `rel-cubism-to-futurism`（影響）: 形態分解という特定技法を速度表現へ転用した説明。
- `rel-symbolism-to-surrealism`（影響）: 内面・夢という一部主題の再導入で、直接後継を主張していない。
- `rel-dutch-to-realism`（影響）: 地域・時代を隔てた主題伝統の作用で、直接系譜ではない。

## 次の編集手順

1. 各候補の `sourceIds` と原資料を再読する。
2. 運動全体の構造か、一部作家・技法の作用かを分ける。
3. 一つの関係に継承と反発が併存する場合、単一 kind の限界を記録し、必要なら将来の複合タグ設計として扱う。
4. 変更する場合は note と出典も同時に更新し、関係種別だけを置換しない。
